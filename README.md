# シフト自動生成

給与目標・出勤日数・休みの希望などの条件を入力すると、それらをできるだけ満たす
1か月分の勤務スケジュールを自動生成するWebアプリです。

- **サーバー不要・完全無料**: すべての処理はブラウザ内のJavaScriptで完結します
  (AIも外部APIも使っていません)。データもiPhone内(ブラウザのlocalStorage)に
  保存されるだけなので、月額費用は一切かかりません。
- **オフラインでも使える**: PWA(ホーム画面に追加できるアプリ)として作ってあり、
  一度開けばオフラインでも動きます。

## 仕組み(アルゴリズム)

「絶対条件」を守りながら候補スケジュールを2,000〜3,000パターンほどランダムに
生成し、それぞれを

- 給与目標との近さ
- 出勤日数目標との近さ
- 休みたい曜日がどれだけ休めているか
- 連休の作りやすさ

でスコアリングし、上位候補をさらに「1日ずつ入れ替えてスコアが上がるか試す」
という改善(ヒルクライミング法という古典的な最適化手法)にかけて仕上げます。
AIではなく、通常のアルゴリズムだけで動いています。

## デプロイ方法(GitHub Pagesで無料公開)

すでにGitHubアカウント(`aqroo`)をお持ちなので、以下の手順で公開できます。

### 1. リポジトリを作る

https://github.com/new で新しいリポジトリを作成(例: `shift-app`)。
Public/Privateどちらでも構いません(個人利用ならPrivateでもGitHub Pagesは使えます
が、Privateの場合は有効化にGitHub Pro等が必要な場合があります。個人情報を含まない
アプリなのでPublicで問題ありません)。

### 2. ファイルをアップロード

このフォルダの中身(`index.html`, `styles.css`, `app.js`, `scheduler.js`,
`manifest.json`, `sw.js`, アイコン画像)を、そのリポジトリにアップロードします。

ローカルにGit環境があれば:

```bash
cd shift-app
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/aqroo/shift-app.git
git push -u origin main
```

GitHubのWeb画面から直接ドラッグ&ドロップでアップロードしても構いません。

### 3. GitHub Pagesを有効化

1. リポジトリの「Settings」→「Pages」を開く
2. 「Source」を `Deploy from a branch` にし、ブランチを `main` / フォルダを
   `/ (root)` に設定して保存
3. 数分待つと `https://aqroo.github.io/shift-app/` でアクセスできるようになります

## iPhoneのホーム画面に追加する

1. Safariで公開したURLを開く
2. 共有ボタン(四角に上矢印のアイコン)をタップ
3. 「ホーム画面に追加」を選択

これで、アプリのようにホーム画面から直接起動できるようになります
(オフラインでも動作します)。

## データについて

入力した条件や生成したスケジュールは、すべてiPhone内のブラウザストレージに
保存されます。サーバーには一切送信されません。機種変更やブラウザのデータ削除を
行うと、保存内容も失われる点にはご注意ください。
