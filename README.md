# シフト自動生成

給与目標や休みの希望を入力するだけで、条件に合った1か月分の勤務スケジュールを
自動で組んでくれる、個人利用向けのWebアプリです。

サーバーもAIも使わず、ブラウザ内のJavaScriptだけで完結する軽量なツールです。

## 特徴

- **サーバー不要・完全無料** — すべての処理はブラウザ内で完結。データもiPhone内
  (localStorage)に保存されるだけなので、運用コストは一切かかりません。
- **AI不使用** — 「候補を大量生成 → スコアリング → 局所探索で改善」という
  古典的な最適化アルゴリズムだけで動いています(詳細は後述)。
- **オフライン対応** — PWA(ホーム画面に追加できるアプリ)として作られており、
  一度開けばオフラインでも動作します。
- **その場で手動調整できる** — 生成結果はカレンダー上でタップして出勤/休みを
  切り替え可能。給与や日数はその場で再計算されます。
- **複数パターンから選べる** — 上位3件の候補を、給与・最大連勤・最長連休の
  違いとともに比較できます。

## 仕組み(アルゴリズム)

AIではなく、以下のような古典的な最適化手法で動いています。

```
1. 絶対条件(固定休・絶対に休みたい日・最大連勤など)を守りながら、
   候補スケジュールを2,000〜3,000パターンほどランダムに生成する

2. 各候補を、以下の観点でスコアリングする
   - 給与目標との近さ
   - 出勤日数目標との近さ
   - 休みたい曜日がどれだけ休めているか
   - 連休の作りやすさ

3. スコア上位の候補を、1日ずつ入れ替えながら
   スコアが上がる限り改善し続ける(ヒルクライミング法)

4. 最終的に、上位の異なるパターンをいくつか提示する
```

条件を満たすスケジュールが存在しない場合(例: 固定休が多すぎて最低出勤日数を
満たせない)は、その理由を具体的に表示します。

## 技術スタック

- HTML / CSS / JavaScript(素の実装、フレームワーク・ビルドツールなし)
- データ保存: ブラウザの `localStorage`(サーバー送信なし)
- PWA(Web App Manifest + Service Worker によるオフライン対応)

## ファイル構成

```
shift-app/
├── index.html          画面構造
├── styles.css          スタイル
├── app.js              画面ロジック・状態管理・保存処理
├── scheduler.js         スケジュール生成アルゴリズム本体(DOM非依存)
├── manifest.json        PWA設定
├── sw.js                Service Worker(オフライン対応)
├── icon-192.png / icon-512.png / apple-touch-icon.png
└── screenshots/          このREADME用のスクリーンショット
```

`scheduler.js` はDOMに依存しない純粋な関数群になっており、Node.js上でも
単体で読み込んでテストできます。

## ローカルで動かす

ビルド不要です。適当なローカルサーバーで `index.html` を配信するだけで
動作します。

```bash
cd shift-app
python3 -m http.server 8000
# http://localhost:8000 を開く
```

(ブラウザで `index.html` を直接開くだけでも動きますが、Service Workerの
登録にはHTTP経由でのアクセスが必要です。)

## 公開する(GitHub Pages・無料)

1. GitHubで新しいリポジトリを作成し、このフォルダの中身をアップロード
2. リポジトリの **Settings → Pages** を開く
3. **Source** を `Deploy from a branch` にし、ブランチを `main` /
   フォルダを `/ (root)` に設定して保存
4. 数分待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

## iPhoneのホーム画面に追加する

1. Safariで公開したURLを開く
2. 共有ボタン(四角に上矢印)をタップ
3. 「ホーム画面に追加」を選択

以降はアイコンから直接起動でき、オフラインでも動作します。

## データとプライバシー

入力した条件・生成したスケジュールは、すべて端末内のブラウザストレージに
保存されます。外部サーバーへの送信は一切行いません。ブラウザのデータを
消去したり機種変更したりすると、保存内容も失われる点にご注意ください。
